# 视觉对比豁免名单
#
# 用途：某些页面的「原型」还没跟上 App（原型里是占位/旧文案），并排对比必然差异很大。
# 这类差异不是回归，但也不能静默——命中这里的条目仍然会打印差异百分比、
# 仍然会出现在 test:web 的汇总里，只是标注为「已豁免」而不算需要处理的告警。
#
# 格式：<文件名或路径前缀>  <制表符或空格>  <原因>
# 必须以 # 开头写注释；不带原因的行会被忽略。
#
# 退出条件（什么时候把它删掉）：原型补上对应页面后，删掉这一行，差异应该自然降到阈值内。
# 如果删掉之后还是超阈值，说明是 App 走样了，要修界面而不是加回豁免。
